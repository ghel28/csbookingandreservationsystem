# CS Lab Reservations

A browser-based laboratory booking and reservation app for the College of Saint Lawrence Computer Science Department.

**Open the live site:** [CS Lab Reservations](https://mintiesabog.github.io/csbookingandreservationsystem/)

The app lets visitors browse lab availability, submit booking requests, track approval and payment status, and view reservation passes. Profile and reservation data are stored locally in the visitor's browser.

## Source

The site files are in [`booking & reservation system/`](booking%20%26%20reservation%20system/). GitHub Pages publishes the app from the repository root.
